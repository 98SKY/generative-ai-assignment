# Task 8: Bias & Variance

## 1. What is Bias?

Bias is the error caused by overly simple assumptions in a machine learning model.

High bias leads to underfitting.

---

## 2. What is Variance?

Variance is the sensitivity of a model to small changes in training data.

High variance leads to overfitting.

---

## 3. Relationship with Underfitting and Overfitting

- High Bias → Underfitting
- High Variance → Overfitting

A good model balances both bias and variance.

---

## 4. How Can We Reduce Overfitting?

- Use more training data
- Reduce model complexity
- Apply regularization
- Use cross-validation
- Perform feature selection
