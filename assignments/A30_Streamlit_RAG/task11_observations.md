# Observations

## 1. Why Groq is suitable for RAG chatbots

Groq provides extremely low latency responses and is ideal for real-time applications.

---

## 2. Difference between Groq RAG and OpenAI RAG

Both use the same RAG architecture.

The primary difference is the LLM provider.

Groq is generally faster while OpenAI often offers stronger reasoning.

---

## 3. Role of Streamlit

Streamlit allows rapid prototyping of GenAI applications with minimal frontend development effort.
