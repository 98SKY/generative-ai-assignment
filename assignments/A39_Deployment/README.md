# Assignment 39: GenAI Application Deployment

## Objective

Deploy a Generative AI application using:

1. Streamlit Cloud
2. Hugging Face Spaces

## Selected Application

ChatGroq RAG Chatbot built in Assignment 30.

## Deployment Platform 1: Streamlit Cloud

### Steps

1. Push source code to GitHub.
2. Create Streamlit Cloud application.
3. Connect GitHub repository.
4. Configure secrets.
5. Deploy and test application.

### Result

Application successfully deployed and accessible through a public URL.

## Deployment Platform 2: Hugging Face Spaces

### Steps

1. Create a Streamlit Space.
2. Upload project files.
3. Configure environment variables.
4. Build and deploy application.

### Result

Application successfully deployed and accessible through a public URL.

## Files Included

* app.py
* requirements.txt
* README.md
* .env.example

## Technologies Used

* Python
* Streamlit
* LangChain
* Groq API
* FAISS
* Hugging Face Spaces

## Testing

Verified:

* Application loads correctly
* User can upload documents
* Questions are answered correctly
* Error handling works properly

## Conclusion

The GenAI application was successfully deployed on both Streamlit Cloud and Hugging Face Spaces, making it accessible through a web interface without requiring local setup.
