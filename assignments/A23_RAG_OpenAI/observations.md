# Task 11 Answers

## 1. Retriever-Based RAG vs Normal Prompting

Normal prompting relies only on the LLM's training data. RAG retrieves external documents and provides them as context before generating an answer.

## 2. Why Vector Stores Are Critical

Vector stores enable efficient semantic search over embeddings and help retrieve the most relevant documents.

## 3. MMR vs Similarity Search

Similarity search returns the closest matches. MMR balances relevance and diversity, reducing duplicate information.

## 4. Benefits of Multi-Query Retrieval

Different query formulations improve recall and help retrieve more relevant documents.

## 5. Importance of Contextual Compression

It removes irrelevant text and sends only the most useful information to the LLM, reducing token usage and improving answer quality.
