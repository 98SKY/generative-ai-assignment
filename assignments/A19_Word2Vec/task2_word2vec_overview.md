# Task 2: Word2Vec Overview

## What is Word2Vec?

Word2Vec is a shallow neural-network based technique that converts words into meaningful dense vectors.

## Predicting Words from Context

Example:

"I love machine ____"

Model predicts:

learning

## Terminologies

Vocabulary:
All unique words in dataset.

Context Window:
Number of surrounding words considered.

Embedding Dimension:
Length of generated vector.

Example:

100 dimensions
300 dimensions
