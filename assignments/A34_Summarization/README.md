# Assignment 34: Text Summarization using LangChain

## Objective

Build multiple document summarization pipelines using LangChain and compare different summarization strategies.

The assignment covers:

* Prompt-based Summarization
* Stuff Chain
* Map-Reduce Chain
* Refine Chain
* Reusable Summarization Utility

---

## Technologies Used

* Python
* LangChain
* Groq / OpenAI / Ollama
* HuggingFace Embeddings (optional)
