# Assignment 8 – Streamlit Apps

This project contains four basic Streamlit apps demonstrating input components, buttons, sidebar usage, and simple visualizations.

## Folder Structure

A8_Streamlit
│
├── app_basic.py
├── app_discount.py
├── app_product_form.py
├── app_dashboard.py
└── README.md

## Requirements

Install Streamlit:

pip install streamlit

## How to Run

Run each task individually.

Task 1 – Basic App

streamlit run app_basic.py

Task 2 – Price Calculator

streamlit run app_discount.py

Task 3 – Product Form

streamlit run app_product_form.py

Task 4 – Sales Dashboard

streamlit run app_dashboard.py

## Description

Task 1 – Greeting App  
Takes user name input and displays greeting message.

Task 2 – Price Calculator  
Calculates final price after applying discount.

Task 3 – Product Form  
Uses Streamlit sidebar to add product details.

Task 4 – Sales Dashboard  
Displays monthly sales using metric and bar chart.
