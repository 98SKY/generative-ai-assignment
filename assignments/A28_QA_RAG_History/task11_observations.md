# Assignment 28 Observations

## 1. Difference between normal RAG and conversational RAG

Normal RAG answers a single query.
Conversational RAG uses retrieval plus chat history.

---

## 2. Role of message history

Message history helps understand follow-up questions.

---

## 3. Trade-offs between long memory and performance

More memory improves context but increases token usage and latency.

---

## 4. How trimming affects answer quality

Trimming reduces token usage but may remove useful context.
