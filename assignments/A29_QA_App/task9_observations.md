# Assignment 29 Observations

## 1. When to prefer OpenAI models

Use OpenAI when high accuracy and reasoning quality are required.

## 2. When to prefer open-source models

Use Ollama when privacy, offline access, and cost savings are important.

## 3. Trade-offs in production systems

OpenAI provides better quality.
Open-source models provide more control.

## 4. Cost and scalability considerations

OpenAI incurs token-based costs.
Open-source models require hardware resources but no per-request fees.
