# Task 1

## 1. What are SystemMessage, HumanMessage, and AIMessage?

SystemMessage:
Provides instructions to the model.

HumanMessage:
Represents user input.

AIMessage:
Represents model responses.

---

## 2. Why message-based prompting is better than single prompts?

- Maintains conversation context
- Separates roles clearly
- Improves multi-turn conversations
- Used by modern chat models
