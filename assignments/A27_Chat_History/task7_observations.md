# Task 7

## 1. Why chat history is important?

It enables context-aware conversations and follow-up questions.

---

## 2. Trade-offs between long memory and performance?

Long history improves context but increases token usage and latency.

---

## 3. When to summarize vs trim history?

Summarize:
When important context must be retained.

Trim:
When old messages are no longer useful.

---

## 4. Difference between message placeholders and memory?

Message Placeholder:
Injects history into prompts dynamically.

Memory:
Stores and manages conversation history automatically.
