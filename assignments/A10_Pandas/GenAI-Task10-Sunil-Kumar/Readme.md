# Assignment 10: Pandas Analysis

## Project Overview
This project involves analyzing student performance and sales data using the Python Pandas library. It covers Series operations, DataFrame manipulation, filtering, grouping, and basic data visualization.

## Tasks Completed
- **Task 1-3:** Pandas Series basics, mathematical operations, and descriptive statistics.
- **Task 4-5:** DataFrame creation from dictionaries and essential inspection functions.
- **Task 6-7:** Conditional filtering and data aggregation using `groupby()`.
- **Task 8:** Built-in Pandas plotting (Bar, Line, and Histogram).
- **Task 9:** Mini use case analyzing daily sales revenue.
