# Task 1: Understanding Tools

## 1. What is a Tool in an AI Agent?

A tool is a function or external capability that an AI agent can use to perform actions beyond text generation.

Examples:

* Calculator
* Search Engine
* Database Query
* API Call

---

## 2. Why do agents need tools?

LLMs cannot always:

* access current information
* perform accurate calculations
* query external systems

Tools extend their capabilities.

---

## 3. Difference between Chatbot and Agent

Chatbot:

* Generates responses only.

Agent:

* Reasons about a task.
* Chooses tools.
* Executes actions.
* Returns results.
