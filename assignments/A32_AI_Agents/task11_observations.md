# Observations & Insights

## 1. Benefits of Tool-Augmented Agents

* Access external information
* Perform calculations
* Interact with systems
* Reduce hallucinations

---

## 2. Challenges with Agents

* Tool selection errors
* Increased latency
* More complex debugging

---

## 3. Difference Between Chains and Agents

Chains:

* Fixed workflow

Agents:

* Dynamic decision making

---

## 4. When to Use Agents Over RAG

Use Agents when:

* Multiple tools are required
* Actions must be performed
* Reasoning and planning are needed

Use RAG when:

* Retrieval from documents is sufficient
