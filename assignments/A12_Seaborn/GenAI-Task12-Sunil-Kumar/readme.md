# Assignment 12: Seaborn EDA

## Project Overview
This project performs a comprehensive Exploratory Data Analysis using Seaborn. It covers relational, distribution, categorical, regression, and matrix plots.

## Dataset
- **Source:** Kaggle
- **Requirements:** Includes at least 2 numerical columns and 1 categorical column.

## Tasks Completed
- Relational and Scatter Plots
- Distribution (Hist, KDE, Rug) and Bivariate analysis
- Matrix plots (Heatmap, Pairplot)
- Categorical and Regression plots
- FacetGrid and Multi-plot Dashboards
