# Assignment 38: CodeLlama Coding Assistant

## Objective

Build an AI Coding Assistant capable of:

* Generating Python code
* Explaining code
* Debugging code
* Optimizing code

## Features

### Code Generation

Generates Python code from natural language prompts.

### Code Explanation

Explains existing code in simple language.

### Bug Fixing

Identifies issues and suggests corrected code.

### Code Optimization

Improves performance and readability.

## Technologies Used

* Python
* Streamlit
* Groq API
* LangChain Concepts
* Llama 3.1 8B

## Project Structure

app.py

codellama_assistant.py

prompts.py

requirements.txt

.env

README.md

## How to Run

1. Install dependencies

pip install -r requirements.txt

2. Add Groq API key to .env

3. Run application

streamlit run app.py

## Sample Tests

### Generate Code

Write a Python function to check prime numbers.

### Explain Code

Explain a recursive factorial function.

### Debug Code

Find the bug in a Python loop.

## Conclusion

The application demonstrates how large language models can assist developers with code generation, explanation, debugging, and optimization through a simple Streamlit interface.
