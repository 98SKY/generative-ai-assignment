# Task 10: Observations & Insights

## 1. Difference Between Basic and Advanced Cleaning

Basic Cleaning:
- Lowercasing
- Removing punctuation
- Removing numbers
- Removing extra spaces

Advanced Cleaning:
- URL removal
- Email removal
- HTML tag removal
- Emoji removal
- Noise removal

Advanced cleaning produces cleaner and more meaningful text.

---

## 2. Why Lemmatization is Preferred Over Stemming

Stemming simply cuts words.

Example:
running → run
studies → studi

Lemmatization returns dictionary words.

Example:
running → run
studies → study

Therefore, lemmatization preserves meaning better.
