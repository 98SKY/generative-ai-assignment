# Assignment 35 - Text-to-Math Agent

## Objective

Build a LangChain Agent capable of solving mathematical word problems and maintaining session history.

---

## Features

* Mathematical reasoning
* Calculator tool integration
* LangChain Agent
* Conversation history using Streamlit Session State
* Step-by-step reasoning

---

## Files

### task1_overview.md

Conceptual answers.

### task2_math_agent.py

LangChain Math Agent implementation.

### task3_streamlit_app.py

Interactive Streamlit application.

---

## Installation

```bash
pip install -r requirements.txt
```

---

## Run Agent

```bash
python task2_math_agent.py
```

---

## Run Streamlit App

```bash
streamlit run task3_streamlit_app.py
```

---

## Example Questions

* What is 25% of 400?
* What is 45 × 78?
* A product costs ₹1500 and receives 20% discount. What is the final price?
* Solve 35 + 25 * 4

---

## Learning Outcomes

* LangChain Agents
* Tool Usage
