# Assignment 9 – NumPy (Mathematical & Statistical Operations)

## Overview

This assignment demonstrates the use of **NumPy** to perform mathematical computations, array operations, and statistical analysis on numerical data.
The goal is to understand NumPy fundamentals that are essential for **Data Analysis, Machine Learning, and Data Science**.

Navigate to the project folder and run the script:

