# Assignment 20: Recommendation System

## Dataset

TMDB Movie Recommendation Dataset

## Technologies Used

* Python
* Pandas
* Scikit-Learn
* TF-IDF
* Cosine Similarity
* Streamlit
* GitHub
* Render

## Features

* Text preprocessing
* TF-IDF vectorization
* Cosine similarity
* Content-based recommendations
* Streamlit UI
* Cloud deployment

## Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Run application:

```bash
streamlit run app.py
```

## Deployment

1. Push project to GitHub
2. Connect GitHub repository to Render
3. Deploy using:

Build Command:

```bash
pip install -r requirements.txt
```

Start Command:

```bash
streamlit run app.py --server.port $PORT --server.address 0.0.0.0
```
