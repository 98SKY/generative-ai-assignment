# Assignment 11: Matplotlib Visualization

## Overview
This project demonstrates the use of core Matplotlib functions to create various data visualizations, including line, scatter, bar, histogram, and pie charts.

## Restrictions Followed
- Used only `matplotlib.pyplot`.
- No Seaborn or Pandas plotting shortcuts used.
- Plots are kept simple and readable.
